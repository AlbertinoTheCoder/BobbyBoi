# BobbyBoi 2.1.2 — Jailhouse renovation

I rebuilt the desktop jail with stone-brick walls, a crenellated roofline, warm lanterns, a bed, a proper sign and a single hinged iron gate. BobbyBoi stays visible behind the gate and walks out when his sentence ends; the golem leaves ahead of him.

I also cleaned up the repository root, moved the app into `src/BobbyBoi`, and added the PolyForm Noncommercial License 1.0.0 for my original code and assets. The license and required notice are included in the Windows download.

Extract **BobbyBoi-Windows-x64.zip** and run **BobbyBoi.exe**. Windows 10/11 x64, self-contained runtime. Existing settings and inventory are preserved.
